# 교육 내용 정리 (강의 목차에서 우리 프로젝트와 연결되는 부분 발췌)

교육 강의 목차에서 우리 프로젝트(클릭베이트 탐지 에이전트와 인간 감독)에 필요한 강의를 뽑아, 챕터별로 하나씩 정리하는 폴더입니다. 운영팀 공지(11/5)와 멘토 답변에서 이번 대회의 중점이 인간 감독(Human Oversight)이라고 했기 때문에, 인간 감독과 직접 연결되는 강의부터 정리합니다.

## 작성 원칙
- 강의 본문을 확인한 강의는 본문에 나온 내용만 정리하고, 아직 확인하지 않은 강의는 제목 기준 메모로 두었다가 확인하면 같은 형식으로 바꿉니다. 해석이나 프로젝트 적용은 넣지 않습니다.
- 요약은 강의 문장을 옮기지 않고 우리 말로 정리합니다. 저장소가 공개될 수 있으므로 강의 대본, 슬라이드, 캡처는 올리지 않습니다.
- 강의를 듣고 확인한 내용은 챕터 파일 맨 아래 "강의 확인 기록" 표에 적습니다. 확인자와 핵심 1~2줄을 남깁니다.
- 프로젝트 적용은 별도로 함께 검토하면서 정합니다.
