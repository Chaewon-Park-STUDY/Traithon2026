# 시연 자료 (데이터과학 초안, 2026-11-06)

## 시연 영상
- 파일: `레드투그린_시연_2026-11-06.mp4` (1분 26초, 1440×900, 무음). 기사 원문이 화면에 나오므로 저장소에 올리지 않고 소이 PC에 보관 중이며, 제출 시 링크로 공유한다.
- 녹화 환경: 운영팀 GPU 서버(H100)에서 A.X 4.0 Light 미세조정 어댑터로 실제 추론.

## 영상 순서
1. 기사 검토 탭, 예시 5건 (AI-Hub 테스트 셋, 학습에 쓰지 않은 기사)
   - ① 정상 기사 → 자동 통과
   - ② 사람이 끼워 넣은 이탈 문장 → 낚시성 확정 대기열 (사람 승인 후 표시), A.X가 이탈 문장 번호를 근거로 제시
   - ③ 애매한 기사 → 사람 검토 (애매)
   - ④ 정치 기사 → 사람 검토 (의무)
   - ⑤ 판정 강요 지시문이 든 기사 → 판단 보류 (지시문 탐지)
2. 운영 모니터 탭, 용량 초과 대응 규칙 (BaseKit Part B 5-B6)
   - 검토자 3명: 사용률 84% → 정상
   - 하루 750건·2명: 94% → 경고 (운영 책임자 알림)
   - 하루 1,000건·2명: 125% → 확정 대기열 게시 보류
   - 3일 연속 초과·30시간 대기 → 자동 처리 중지

## 코드
- 앱: `src/datascience/gpu/demo_app.py` (Gradio), 예시 추출: `src/datascience/gpu/demo_examples.py`
- 판정 규칙은 `results/calibration_axft_maxq.json`의 임계값(α=0.05)을 그대로 사용한다.
- 지시문 탐지는 정규식 패턴 방식의 시연용 구현이다. 실서비스에서는 별도 탐지 모델과 함께 써야 한다.
