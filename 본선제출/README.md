### 1. BaseKit 1~7 최종 산출물
- 모든 필수 항목을 작성한 최종본입니다.
- 파트 C는 필요할 때만 선택 작성합니다.
- 예선 때 쓴 BaseKit 1~2 완성본과 BaseKit 3~7 기획본(파트 A)을 바탕으로 본선에서 실제 수행한 결과를 채워 넣습니다.
- 확인할 것: 평가 가정(A1~A5)을 실제 값으로 바꿨는지, 아직 모르는 것으로 남긴 항목을 본선에서 확인했는지, ID(IMPACT, RISK, TLD, DATA, MDL, HO, OPS) 상호 참조가 맞는지.

### 2. 산출물 시연 자료
- 시연영상 또는 웹사이트 링크 등 동작을 보여 주는 자료입니다.
- 링크로 제출할 때는 접근 권한을 열어 두고, 링크를 `2_시연자료/links.md`에 적어 둡니다.

### 3. Traceability Matrix
- HTML 또는 Excel 형식입니다.
- BaseKit의 ID(영향, 위험, 투명성, 데이터, 모델, 인간 개입, 운영)가 서로 어떻게 이어지는지 한 표로 보여 줍니다.

### 4. 팀 소개 및 결과요약서
- 운영팀이 공지한 Google 문서 양식을 내려받아 작성합니다.
- 양식 링크: https://docs.google.com/document/d/1JFhvOqcRggwXlvyUCeSpdCI_f8lsAd1T/edit

### 5. 결과 발표영상
- 약 10분 분량입니다.
- 제작 가이드는 운영팀의 별도 공지를 확인해서 반영합니다.
