# 사전 등록: OPS-01 감사 표본 설계 (d26)

상태: 초안 (2026-11-07). `d26_audit_design.py`의 결과를 보기 전에 커밋한다.
대상: `axft_maxq`, main test 3,232건 (`outputs/test_decisions_axft_maxq.csv`). 점수 순서(부분 2)는 같은 폴더의 `scores_*.csv`의 `p_cb`를 `news_id`=`key`로 합쳐 쓴다.

## 질문
1. 자동 통과(set={normal}, 비민감)에서 무작위로 n건을 뽑아 사람이 라벨링하면, 놓침(miss)이 α를 넘었을 때 감사가 경보를 울릴 확률은 n에 따라 어떻게 변하는가. 기획본의 203건은 그 곡선의 어디에 있는가.
2. 자동 통과를 모델 점수 `p_cb` 순으로 줄 세우면 놓친 클릭베이트가 앞쪽에 몰리는가(층화 감사가 이득인가).

## 고정하는 규칙
1. **감사 대상**은 비민감 자동 통과 D. 민감(정치·경제)은 항상 사람이 보므로(HO-02) 제외한다.
2. **감사하는 양(주 정의 B)**: miss = P(자동 통과 | 클릭베이트). conformal 보장은 클래스 조건부 미포착률 ≤ α이므로 감사는 이 보장을 겨냥한다. α = 0.05 (`common.POLICY`).
3. **보조 정의 A**: 기획본의 "미커버율" 해석, 즉 D 안의 클릭베이트 비율 κ ≤ α. 같은 표에 함께 보고한다.
4. **κ와 miss의 관계**: κ(m) = π·m / (π·m + (1−π)·pn). pn = P(자동 통과 | 정상, 비민감)은 test에서 추정한다. π는 연속 격자(0.05~0.50)로 보이며 특정 값을 고르지 않는다.
5. **경보 규칙**: 단측 정확 이항검정. H0: κ ≤ κ0 (정의 B에서 κ0 = κ(α), 정의 A에서 κ0 = α). 검사 수준 ≤ δ = 0.05(`common.POLICY`의 δ를 재사용. 이 재사용은 팀 결정 사항이다). 표본 n에서 클릭베이트가 임계 건수를 넘으면 경보.
6. **경보 확률 곡선**: 진짜 miss를 α의 배수(1, 1.5, 2, 3배, 표시용 격자)와 test에서 관측한 miss(점추정과 Clopper–Pearson 95% 끝점)로 두고, n 격자에서 경보 확률을 낸다. 진짜 miss가 α이하이면 이 값은 검정력이 아니라 오경보 확률이다. 203건을 모든 표에 포함한다.
7. **80% 검정력에 필요한 n**은 참조용으로만 낸다(통계의 관례이며 근거가 있는 기준이 아니다). 결정 기준으로 쓰지 않는다. 표본 크기는 여러 n의 곡선을 보고 팀이 정한다.
8. **점수 순서(부분 2)**: D를 `p_cb` 내림차순으로 놓고 상위 x 비율을 감사했을 때 잡히는 놓친 클릭베이트 비율 y를 보인다(무작위면 y=x). 클래스 비율을 서비스 π로 맞추기 위해 행 가중치 = π/클릭베이트 수(클릭베이트), (1−π)/정상 수(정상)를 쓴다. 보조로 D 안의 클릭베이트 대 정상 AUC를 보고한다(0.5면 점수 순서가 놓침을 찾지 못함). 층의 경계는 정하지 않는다.
9. **불확실성**: 비민감 test 행을 클래스별로 재표집하는 bootstrap(B=2,000, 시드 고정), 백분위 95% 구간. 놓친 클릭베이트 건수가 적으면 구간이 매우 넓으며 그대로 보고한다.
10. **해석 규칙**: 임계값으로 결론짓지 않고 구간과 곡선으로 보고한다. 구간이 넓으면 "이 표본으로는 판단할 수 없음"으로 쓴다.

## 한계 (결과 해석 전에 명시)
- 감사 라벨을 사람이 정확히 단다고 가정한다(h=0). 라벨러 오류가 있으면 κ와 miss 모두 왜곡된다.
- pn과 관측 miss는 한 모델, 한 분할의 값이다. 운영에서는 분포 변화로 바뀔 수 있다.
- 기획본 203건은 z²·α(1−α)/ε² 공식에서 ε=0.03일 때의 값(202.8)으로 역산한 것이다. [확인 필요: 기획본의 ε]
- 정의 B로의 환산은 π(클릭베이트 비율)를 가정하며, 운영에서는 감사 시점에 관측한 건수(확정 후보에서 사람이 찾은 클릭베이트 수, D의 크기)로 miss를 직접 계산해야 한다.
- 부분 2는 같은 test의 놓친 건으로 만든 순서이며 독립 검증이 아니다.
