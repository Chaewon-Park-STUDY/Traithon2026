# PREREG d33: 감사 표본 크기의 ε-δ 비교와 보정 표본 변동

작성일: 2026-11-08 (코드 실행 전). 근거: 수리통계(Chebyshev 부등식, 대수의 법칙/확률수렴, Hoeffding, Bernstein, Clopper-Pearson), conformal prediction의 보정 조건부 분포(Beta), d26b·d28·d31·d32. 레포 출력 파일은 읽지 않는다(선택적으로 split_manifest의 보정 표본 수만 읽음).

## 질문
(a) 클릭베이트 놓침률 m을 반폭 ε 이내로 신뢰수준 1-δ에 추정하려면 라벨 감사에 몇 건이 필요한가(방법별 보장의 차이). 자동 통과 풀에서 뽑아야 하는 기사 수는 얼마인가. (b) 보정 표본 크기가 유한할 때, α로 보정해도 실현 놓침률이 α를 넘을 확률은 얼마이고, 95%로 맞추려면 α를 얼마로 낮춰야 하는가.

## (a) 정의 (고정, δ=0.05, ε∈{0.01, 0.02, 0.03, 0.05}, m∈{0.02, 0.0307, 0.05, 0.10})
- CLT: n=z²·m(1-m)/ε² (정규근사, 보장 아님). Chebyshev: n=m(1-m)/(δ·ε²). Hoeffding: n=ln(2/δ)/(2ε²). Bernstein(|X-m|≤1): n=(2m(1-m)/ε²+2/(3ε))·ln(2/δ).
- Exact: k=round(n·m)에서 Clopper-Pearson 양측 구간의 큰 쪽 반폭이 ε 이하가 되는 최소 n(대표값 기준). 별도로 m을 모를 때 모든 k에 대해 반폭 ≤ ε인 최소 n(ε=0.03, 0.05, 최악 k).
- 자동 통과 풀 감사 건수 = Bernstein 건수 / κ, κ=π·m/(π·m+(1-π)·pn), pn=0.9571(d32 출력의 정상→자동 통과율), π∈{0.05, 0.10, 0.25}. 라벨 없는 풀에서 클릭베이트가 드물어 필요한 감사 건수가 크게 늘어난다는 점을 보이기 위한 격자이며 표시용.
- 읽는 법: 보장이 필요하면 Bernstein 이상, 계획용 대표값은 Exact.

## (b) 정의 (고정)
- 교환가능성과 연속 점수 가정에서 class-조건부 보정이 주어졌을 때 실현 놓침률 M ~ Beta(l, n+1-l), l=floor((n+1)·α) (Vovk, Angelopoulos–Bates). n=해당 임계값을 만든 클릭베이트 보정 표본 수(Direct, auto_check, category별).
- 보고: 기대 놓침 l/(n+1), M의 5·95분위, P(M ≤ α), 그리고 P(M ≤ α) ≥ 0.95를 만족하는 ALPHA 이하 최대 보정용 α'(격자 0.0005). 이 α'는 유한 보정 표본에서의 PAC형 조정이며 검토량 비용은 d28 곡선에서 읽는다.
- maxq는 Direct와 auto 각각에 이 식이 적용된다.

## 한계
- 정규 근사(CLT)는 m이 작을수록 부정확하다. Exact는 대표 k 기준이다. (b)는 교환가능성 가정 아래의 이론 분포이며 실제 점수에 동점이 있거나 분포가 이동하면 달라진다. 라벨 감사 표본이 독립추출이라는 가정. 검토자 정확(h=0).
- 숫자 공개는 멘토 확인 후. 출력은 집계뿐이다.
