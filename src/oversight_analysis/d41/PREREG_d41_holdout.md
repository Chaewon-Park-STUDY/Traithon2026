# PREREG d41: 점수를 한 번도 보지 않은 holdout에서 확정 임계값 재검증 (MDL-01 + d34 독립 확인)

작성일: 2026-11-16 (채점 실행 전). 상태: GPU 사용 승인 후 실행. 모델 학습·임계값 재계산은 하지 않는다(고정 임계값 적용만).

## 질문
(1) 보정·시험에 쓰이지 않았고 미세조정 학습에도 쓰이지 않은 새 기사에서도 헤드라인 지표(커버리지, AUC, ECE)가 기준을 만족하는가.
(2) d34의 탐색적 발견("생활&문화 클릭베이트 놓침이 높다. category별 보정이 이를 낮춘다")이 독립 표본에서도 재현되는가. (d34 PREREG: "독립 확인에는 아직 점수를 매기지 않은 데이터가 필요하다")

## 데이터 (고정)
- `d41_make_holdout.py --n 2000`: Training 분할에서 hold·개인정보 의심·라벨 없음 제외, split_manifest(보정·시험·dev) 기사 제외, d18 학습 추출분(그룹당 7,000)과 인젝션 증강 원본(700) 제외. 그룹(direct_cb, auto_cb, normal)당 2,000건 = 6,000건. 본문은 앞 1,500자(d18, d40과 같음). seed는 `common.SEED`로 고정.
- 크기 근거: 생활&문화 클릭베이트가 약 345건 들어와 category별 놓침 비율의 신뢰구간이 d34 시험(238건)보다 좁다. n은 점수를 보기 전에 정했다.
- 채점: d40과 같은 어댑터·프롬프트(`ft_score_new.py`). 실행 전 어댑터 sha256 앞 16자리 `d9d5c46239ec1d70` 확인.

## 임계값 (고정, 재계산 금지)
- S0(현행): `calibration_axft_maxq.json`의 q_clickbait, q_normal.
- S1·S2(α=0.05): `d34_out/d34_thresholds_axft.csv`의 category별 q_cb, q_ok.
- 규칙: 클릭베이트 후보 = (1−p) ≤ q_cb, 정상 후보 = p ≤ q_ok. 둘 중 하나만이면 확정(cb/normal), 둘 다 또는 둘 다 아니면 ambiguous(사람 검토). 정치·경제는 항상 사람 검토(라우팅 전체 비교 때만).

## 지표와 기준 (고정)
기준은 GPU 지원 요청서(11/4)에 적은 성공 기준을 그대로 쓴다.
1. Direct·Auto 클릭베이트 커버리지(= 클릭베이트 후보에 포함된 비율). Clopper-Pearson 95% 구간의 하한 ≥ 0.93. 전체 category 기준이며 비민감만의 값도 함께 보고한다.
2. AUC(클릭베이트 대 정상, 기사 단위 bootstrap B=10,000 95% 구간): 하한 ≥ 0.85.
3. ECE(`common.ece`, 10구간 동일 폭): 같은 bootstrap의 상한 ≤ 0.10. 표본이 정상:클릭베이트 = 1:2로 구성되어 있어 모집단 유병률의 ECE가 아님을 명시한다.
4. 정상 쪽: 정상 후보 포함률(커버리지), 정상의 오확정(cb 확정) 비율. 기준 없이 보고(기술).
5. d34 재현(비민감 5개 category): S0·S1·S2 각각 category별 클릭베이트 놓침(= 정상으로 확정되어 자동 통과, d34 정의)과 Clopper-Pearson 95%, exceeds_alpha = (95% 하한 > 0.05). 전체 오확정(fc)과 정상의 ambiguous 비율(amb_normal)을 함께 보고한다(대가).

## 결정 규칙
- 1~3을 모두 만족하면 "고정 임계값이 새 기사에서도 성공 기준을 만족했다"고 쓴다. 하나라도 못 미치면 어느 기준이 얼마나 못 미쳤는지를 한계로 쓰고, 임계값을 다시 조정하지 않는다.
- d34 재현: (a) S0에서 생활&문화 놓침의 95% 하한 > 0.05이면 "약점이 독립 표본에서도 재현됐다". (b) 재현되고 S1 또는 S2의 생활&문화 놓침 95% 상한이 S0의 점추정보다 낮으며 exactMcNemar(같은 기사의 S0 대 S1·S2 결과 불일치) 단측 p < 0.05이면 "category별 보정이 독립 표본에서도 낮췄다". 어느 쪽이든 fc·amb_normal 증가를 같은 문장에 쓴다. 재현되지 않으면 d34의 결과는 탐색적 우연일 수 있다고 쓴다.
- 다른 category와의 비교는 탐색적이며 보정하지 않은 구간을 쓴다.

## 한계 (결과와 무관하게 명시)
- 같은 AI-Hub 분포의 holdout이다. 다른 분포(웹 영어, 새 매체)는 시험하지 않았다. 라벨은 검수하지 않았다(DQ-02).
- 정상:클릭베이트 비율은 설계값이다. 운영 유병률에서의 검토량은 여기서 주장하지 않는다.
- 어댑터 1개, 샘플 분할(전체 660,085건의 공식 분할이 아님).
