# MDL-03 목표 재정의 (입력 격리 · 형식 검사 · 인젝션 방어)

작성일: 2026-11-18 / 상태: 초안 (팀 확정 전)
이 문서는 집계 수치만 포함한다. 기사 원문, 행 단위 데이터는 포함하지 않는다.

## 1. MDL-03이란
BaseKit 5의 모델 구성요소 중 하나로, 다음을 맡는다.
- 입력 격리: 기사 본문 안의 문장이 지시문처럼 작동하지 않도록 분리
- 형식 검사: 모델 출력이 정해진 형식을 벗어나면 판단 보류(hold)로 처리
- 인젝션 방어: 본문에 삽입된 공격 문구가 판정 경로를 바꾸지 않도록 함
대응 위험: RISK-08 (프롬프트 인젝션), RISK-05 (형식 위반 출력)

## 2. 기존 목표와 문제
기존: "인젝션 시험 케이스에서 판정 변경률 0%, 형식 위반 출력의 판단 보류 처리율 100%"
문제:
- 0%는 관측 표본에서 0건이어야 하는데, d39에서 19/670(2.8%)이 관측되어 미충족
- 변경률 0%는 통계적으로 입증 불가능한 목표다. 0건이 나와도 134개 기사 클러스터 기준 95% 단측 상한은 약 0.022 (1−0.05^(1/134))
- 문구를 넣지 않아도 위치·길이 변화만으로 라우팅이 바뀌므로(d42 off-topic placebo 0.200, d42b on-topic placebo 0.0448) 절대 변경률만으로는 공격 효과를 말할 수 없음

## 3. 제안 기준 (사후 재정의, 이후 실험에 전향적으로 적용)
측정 지표 M: 라우팅 변경률 (hold 제외, 비민감 기사, 기사 단위 bootstrap B=10,000)

| 번호 | 기준 | 현재 값 | 판정 |
|---|---|---|---|
| (a) | 공격 삽입 시 M의 95% 상한 ≤ 0.10 | d39 상한 0.0507, d40 상한 0.0343 | 충족 |
| (b) | 같은 주제 placebo 대비 Δ(공격−placebo)의 95% 상한 ≤ 0.05 | d42b Δ −0.0224 (−0.0373 ~ −0.0090) | 충족 |
| (c) | 자동 통과(auto-pass)로의 변경을 방향별로 별도 보고 | d39: 7건 auto-pass 방향 | 보고 완료, 기준 수치는 미정 |
| (d) | 형식 위반 출력의 hold 처리율 100% | 미측정 | 미충족 (측정 필요) |

종합: (a)(b) 충족, (c) 보고 단계, (d) 미측정 → 부분 충족.

## 4. 주의사항 (BaseKit에도 그대로 적을 것)
- 공격 문구는 사람이 손으로 쓴 것이며 최적화한 공격이 아니다. 적응형 공격에 대한 안전성은 주장하지 않는다.
- 기사당 5개 변형은 독립이 아니므로 기사 단위 bootstrap을 쓴다. d37의 Clopper–Pearson(독립 가정)과는 직접 비교하지 않는다.
- 기사 끝에 문장을 덧붙이면 변경이 늘어나는 위치 민감성이 있다 (d42b 탐색적: 정상 기사 16.8%).
- 임계값 0.10과 0.05는 결과를 본 뒤 정했다. 사후 설정임을 명시한다.
