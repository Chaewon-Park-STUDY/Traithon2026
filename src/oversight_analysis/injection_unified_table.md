- 변경(현행 정의): 원본과 처리 결과가 달라진 모든 건. 판단 보류(hold)로 바뀐 건 포함. (박소이 d37, `injection_by_type_axft.csv`)

- 상한: 같은 기사의 5개 변형을 한 묶음으로 보는 기사 단위 bootstrap 95% 단측 상한. 기준선 0.10.
- 소이님 d37 표의 구간은 Clopper-Pearson 95%(양측, 변형 670건을 독립으로 가정)이고 센 대상도 달라 이 표의 상한과 직접 비교하지 않는다. 기준선(0.10)과 비교하는 상한은 이 표의 bootstrap 값을 쓴다.
