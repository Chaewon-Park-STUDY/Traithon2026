# 기준선 검증 결과 (2026-11-02, 작성: 박소이 · 데이터과학자)

A.X 4.0 Light 점수가 나오기 전, 파이프라인 전 과정을 실제 AI-Hub 데이터로 처음 돌린 결과다. 점수 모델은 문자 n-gram TF-IDF + 로지스틱 회귀(기준선)이며 A.X가 아니다.

## 데이터
- AI-Hub 낚시성 기사 탐지 **샘플(경량) 데이터** 267,955건(라벨링 JSON). 공식 Training/Validation 구분이 없어 기사 ID 해시로 90:10 분할(`split_source=id_hash_90_10`). 정식 데이터(660,085건)를 받으면 공식 분할로 다시 돌린다.
- 품질: ID 고유 267,955 / 라벨 누락 0 / 분할 간 중복 0 / 입력 이상(한글 비율 낮음) 3건 / 개인정보 의심(이메일·전화번호 형태) 57건 → 둘 다 분석 제외(DQ-04, DQ-05).
- 분할(시드 20261102, 최소 크기 × 1.5): 보정 클래스별 540(클릭베이트는 Direct만), Auto 점검용 540, dev 1,000, 테스트 3,232(Direct 클릭베이트 884, Auto 1,011, 정상 1,337).

## 결과 (α=0.05, 테스트 셋, 괄호는 Clopper–Pearson 95% 하한)
| 보정 방식 | Direct 커버리지 | Auto 커버리지 | 정상 오확정률 | 애매 이관율 | 자동 통과 비율 |
|---|---|---|---|---|---|
| BaseKit 원안: q̂를 Direct로만 계산 | 0.958 (0.943) 통과 | 0.918 (0.899) **미달** | 0.061 | 0.631 | 0.115 |
| 수정안: q̂ = max(Direct, Auto) | 0.977 (0.965) 통과 | 0.951 (0.935) 통과 | 0.061 | 0.684 | 0.075 |

- 기준선 자체 성능(임계 0.5): 재현율 0.651, 오탐률 0.238, ECE 0.091.
- 카테고리별 클릭베이트 커버리지(원안): 연예 0.892, 생활&문화 0.903이 가장 낮고 경제 0.963, 정치 0.961이 높다. 정치·경제 대 나머지 차이는 0.05 이내.

## 해석
1. **BaseKit 가정 수정 필요(RISK-13).** "Direct로 보정하면 보수적"이라는 예선 가정이 기준선에서는 성립하지 않았다. 이 모델에게는 자동 생성(Auto) 클릭베이트가 더 어렵다. 운영 중에는 유형을 알 수 없으므로 두 유형의 q̂ 중 큰 값을 쓰는 수정안을 제안한다. A.X 점수에서 다시 확인한다.
2. **이관율이 목표(0.30)의 두 배 이상.** 기준선 확률이 거칠어서 대부분이 애매 구간에 들어간다. IMPACT-03(검토 과부하)이 실제로 생길 수 있다는 근거이며, A.X나 파인튜닝이 무엇을 줄여야 하는지 보여 주는 출발점이다.
3. **커버리지 보장은 작동.** 보정 셋과 같은 분포(Direct)에서는 이론값 0.95 근처가 그대로 나왔다. 계산 절차 자체는 맞다.
