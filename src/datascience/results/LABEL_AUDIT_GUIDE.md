# 라벨 재검수 안내 (DQ-02, 담당: 데이터과학자)

파일: `outputs/label_audit.csv` (397건, 원문 발췌 포함이라 저장소에 올리지 않음)

## 무엇을 보나
각 행의 제목(`title`)과 본문 발췌(`body_excerpt`)를 읽고, 데이터의 라벨(`label`, 1=클릭베이트)이 맞는지 판단해 `reviewer_label`에 0 또는 1을 적는다. 라벨을 먼저 보지 말고 판단한 뒤 비교하는 것이 좋다(열을 숨기고 진행).

## 판단 기준 (AI-Hub 정의 그대로)
- **Part1 클릭베이트**: 제목이 본문 내용과 맞지 않거나, 본문에 없는 내용을 과장·암시한다. `title_orig`가 원래 제목이며, 정상 기사는 제목이 원제목과 같다.
- **Part2 클릭베이트**: 본문 중간에 주제와 무관한 문장(광고, 갑작스러운 화제 전환)이 끼어 있다. `evidence_sent`는 데이터가 표시한 이탈 문장 번호다.
- **정상**: 제목이 본문을 정확히 요약하고, 본문이 한 주제로 이어진다.
- 확신이 없으면 `note`에 "애매"라고 적고 판단은 더 그럴듯한 쪽으로 한다. 애매 건수도 따로 센다.

## 끝나면
```
python -X utf8 scripts/d12_label_audit_sample.py --score
```
오류율과 95% 구간이 `outputs/label_audit_result.json`에 저장된다. 오류율 상한이 0.10을 넘으면 BaseKit 4 §4-8 기준에 따라 해당 유형을 보정 데이터에서 제외하는 방안을 검토한다. 두 사람이 나눠 보면 겹치는 50건으로 검수자 간 일치도도 계산할 수 있다.

예상 소요: 건당 30초~1분, 전체 3~6시간.
