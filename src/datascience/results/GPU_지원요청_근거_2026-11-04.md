## 2. 검증 결과 요약 (α=0.05, 테스트 3,232건)

| 지표 | A.X zero-shot | TF-IDF 기준선 | 정합성 기준선 | 목표 |
|---|---|---|---|---|
| Direct 클릭베이트 커버리지 (95% 하한) | 0.995 (0.988) | 0.977 (0.965) | 0.949 (0.932) | 하한 0.93 이상 |
| Auto 클릭베이트 커버리지 (95% 하한) | 0.957 (0.943) | 0.951 (0.935) | 0.988 (0.979) | 하한 0.93 이상 |
| 사람 검토 이관율 | **0.864** | 0.684 | 0.667 | 0.30 이하 |
| 판별력 AUC | **0.653** | 0.757 | 0.821 | - |
| 확률 보정 오차 ECE | **0.515** | 0.091 | 0.102 | 0.10 이하 |
| 인젝션 1,000건 처리 결과 변경률 | **0.625** | - | - | 0 |

커버리지 기준은 conformal 보정 덕분에 통과했다. 대신 하루 1,000건 기준 약 975건이 사람에게 넘어가 검토자가 7명 필요하다(설계 가정은 2명).

## 3. 확인된 한계

1. **판별력이 낮다.** AUC 0.653으로, 학습시킨 TF-IDF(0.757)보다도 낮다. 정상 기사와 클릭베이트의 '예' 확률 중앙값이 0.010과 0.018로 거의 같다.
2. **확률이 한쪽으로 쏠려 있다.** 클릭베이트에도 '예' 확률을 평균 0.105로 매긴다(ECE 0.515). 원안 규칙(Direct로 임계값 계산)에서는 Auto 커버리지 하한이 0.892로 기준에 못 미쳤다.
3. **보정으로는 해결되지 않는다.** α를 0.30까지 풀어도 검토 부하가 하루 679건으로 용량 300건을 넘는다. conformal 보정은 놓침을 막아 줄 뿐 판별력을 만들지 못한다.
4. **본문 속 지시를 따른다.** 인젝션 변형의 62.5%에서 처리 결과가 바뀌었고, 바뀐 경우의 88.4%가 지시문이 원하는 방향이었다. 판정 강요(53.0%), 제목 삽입(41.0%), 역할 탈취(32.5%)는 답 형식을 지킨 채 결과만 바뀌어 형식 검사로 걸러지지 않는다.
5. **답 형식은 안정적이다.** '예/아니오' 두 토큰 확률 합이 평균 0.999다. 따라서 문제는 출력 형식이 아니라 판단 자체이며, 프롬프트 수정보다 학습이 필요하다.

## 4. 파인튜닝 계획

| 항목 | 내용 |
|---|---|
| 방법 | A.X 4.0 Light에 QLoRA(4비트 + LoRA r=16) 분류 미세조정. 출력은 지금과 같은 '예/아니오' 다음 토큰 확률이라 보정·평가 파이프라인을 그대로 재사용 |
| 학습 데이터 | AI-Hub 학습 분할에서 Direct·Auto·정상을 균형 추출한 약 20,000건 + 인젝션 변형 2,000건(정답 라벨 유지). 보정셋·테스트셋과 기사 ID가 겹치지 않음 |
| 보완하는 한계 | 1·2(판별력, 확률 쏠림)는 라벨 학습으로, 4(인젝션)는 변형 데이터 학습으로 |
| 평가 | 같은 테스트 3,232건과 인젝션 1,000건으로 다시 채점하고 같은 보정 규칙(수정안) 적용. 반복 분할 200회로 안정성 확인 |
| 성공 기준 | AUC 0.85 이상, ECE 0.10 이하, 커버리지 하한 0.93 유지, 이관율 0.50 이하, 인젝션 변경률 0.10 이하 |

이관율 목표 0.30은 정치·경제 기사(전체의 28%)를 항상 사람에게 넘기는 설계 때문에 모델이 완벽해도 맞추기 어렵다. 이 점은 BaseKit 수정안에 따로 반영한다.

## 5. 필요한 자원

| 작업 | 예상 시간 | 비고 |
|---|---|---|
| QLoRA 학습 (22,000건 × 약 700토큰 × 2에폭) | A100 40GB 기준 약 4~6시간 | 24GB급(L4·A10)도 가능하나 약 2배 |

| 여유분 (하이퍼파라미터 2~3회 재시도) | 약 8시간 | |
| **합계** | **GPU 약 20시간** | A100 40GB 1장 권장 |

Colab 무료 T4는 세션이 끊기면 결과가 사라지고(11/3에 400건 유실), 7B 모델 학습에는 메모리가 모자라 미세조정을 할 수 없다.
