## 1. 서비스 정의

| 항목 | 내용 |
|---|---|
| 서비스명 | 뉴스 기사 클릭베이트 탐지 Agent |
| 입력 | 뉴스 기사 **제목 + 본문** (텍스트) |
| 출력 | 클릭베이트 여부 판단 · 판단 근거 · 위험도 점수 · 검토 필요 여부 |
| 필수 모델 | [A.X 4.0 Light](https://huggingface.co/skt/A.X-4.0-Light) (SKT, Hugging Face 공개) — 필수 사용, 타 모델 병행 가능 |
| 인간감독 구조 | AI 판단 → **인간감독(검토·승인·보류)** |
| 직접 사용자 | 뉴스 플랫폼 운영팀 — 기사 게시 전 또는 게시 직후 콘텐츠 검토 용도로 사용 |
| Agent 자율범위 | **자율 조치**: 위험도 낮음 → 자동 통과 / **사전 승인 필요**: 클릭베이트 판정 → 검토자 확인 후 게시 보류·경고 표시 / **자동판정 중지(사람에게 이관)**: 정치적으로 민감한 주제, 판단 신뢰도 낮은 경우 |
| 보조 모델 | 현재 단계는 A.X 4.0 Light 단독 운용. 확장 옵션으로 제목-본문 유사도 기반 경량 분류기 추가 검토 |

> **대표 활용 예시**: 서비스는 뉴스 기사 전반을 대상으로 하되, 대표 시나리오로 **금융·증시 뉴스 도메인**을 든다. 특정 종목(예: 반도체 대형주)의 주가 급락·급등을 자극적으로 과장하거나 근거 없는 공포 심리를 조장하는 기사는, 개인 투자자의 비합리적 매매를 유도하고 해당 기업의 평판·주가에 실질적 영향을 줄 수 있어 클릭베이트의 사회적 위해가 큰 사례로 꼽힌다. 서비스 자체는 도메인을 한정하지 않으며, 이는 어디까지나 설명을 위한 예시임을 명확히 한다.

## 2. 사용 데이터

| 구분 | 데이터 | 언어 | 용도 |
|---|---|---|---|
| 메인 | [AI-Hub 낚시성 기사 탐지 데이터](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=71338) | 한국어 | 클릭베이트 탐지, 제목-본문 불일치, 과장·정보 은닉 분석 |
| 보조 | [Webis Clickbait Corpus 2017](https://webis.de/events/clickbait-challenge/shared-task.html) ([다운로드](https://zenodo.org/records/5530410), `clickbait17-train-170630.zip`, 이미지 제외) | 영어 | 클릭베이트 강도, AI-사람 판단 비교, 인간 검토 기준 설정 |

- 두 데이터는 언어·구조가 달라 **목적별로 구분 활용** (단순 병합 지양)
- 정제·가공·증강·주석 추가 가능, 제공 데이터 없이 추가 데이터만 사용 불가
- 추가 데이터 사용 시: 필요 이유 / 기존 데이터 부족한 점 / 보완되는 신뢰성 문제를 설명할 수 있어야 하며, 사전에 멘토·운영팀 확인 권장
- (예시 도메인 검증용) 금융·증시 관련 기사만 별도로 보고 싶을 경우, 메인 데이터 내에서 종목명·증시 관련 키워드로 필터링한 서브셋을 데모·정성평가용으로 구성할 수 있음 (모델 학습은 전체 데이터 기준)

## 3. 정상/비정상 시나리오

**정상 시나리오**
1. 제목-본문 내용 일치 → "정상" 판정, 낮은 위험도
2. 제목이 본문을 과장/왜곡 → "클릭베이트" 판정 + 근거(불일치 구간) 제시

**비정상/예외 시나리오**
1. 본문 누락 (제목만 존재)
2. 언어 혼재, 특수기호 과다
3. 인용문·풍자 포함 → 오탐 위험 (문맥 점검 필요)
4. 정치·경제적으로 민감한 주제(예: 특정 기업·종목 관련 추측성 보도) → 편향·오탐 위험 및 실질적 파급력 큼
5. 검토 대기열 초과 / 검토자 부재 상태에서 판단 요청 발생
