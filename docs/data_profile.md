## 구성 방식 (필드 구조와 표본 관찰 기준, 패턴 코드 의미는 정의서와 대조 필요)
- Part1: `newTitle`(새 제목) + `referSentenceInfo`(근거 문장 Y/N). 본문은 원문.
- Part2: `newTitle` 없음. `processSentenceInfo`(본문 문장 목록, 문장별 `subjectConsistencyYn`), `processSentencenum`(변형 문장 수).
- Auto(패턴 99, 242,812건): 표본에서 무관한 제목·문장으로 대체된 사례 관찰.
- Direct(패턴 11~16: 45,118 / 21~24: 45,124, 90,242건): 강도 상 20,668 · 중 35,755 · 하 33,819.
- 정상: 모두 Auto, 패턴 00(원본 유지).

## 설계에 주는 함의
- 클릭베이트의 약 73%가 자동 생성 변형 → Auto/Direct 분리 평가 (RISK-13).
- 생성 유형은 운영 시 관측 불가 → 클릭베이트 보정은 Direct 표본 기준(보수적), Auto 커버리지는 별도 실측.
